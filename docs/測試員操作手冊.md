# 測試員操作手冊（封閉測試）

> 給受邀測試員的一頁式說明。網址由邀請者提供；帳號 tester1/tester2/tester3，共用密碼 `Guliu2026`。

## 你要做的三件事

1. **登入 → 建立自選股**：「自選」分頁按 ＋ 或上方搜尋框輸入股號（例 2330）。
   可分類（觀察股／蓄勢／水池／靜流）；「水池」可填**成本價**，即可看到自己的損益位置。
2. **看「研判」頁（重點）**：六段結論（已確認／推測／尚需等待）、支撐壓力與結構失效位、
   最近已確認低點、ATR 進場區、9 戰法命中情況。
3. **回報問題**：時間／畫面頁籤／我做了什麼／預期看到什麼／實際看到什麼（附截圖更好）。

## 先知道

- 目前是**盤後資料**（每日約 21:00 更新完成）；盤中即時行情開發中。
- 內容為公開資料整理與研究輔助，**不構成投資建議**。
- 測試帳號請勿轉給他人；各自自選股互不影響。
- 測試期間可能重啟或暫時缺漏資料，回報即可。
